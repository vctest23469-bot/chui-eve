# Chui Eve v1.2.0

新增自选模型 API，用于摘要提炼与思维导图生成。录音与 ASR 仍在本机；提炼时仅向所选服务发送记录标题及转写文字。

项目原创代码以 MIT 许可证开源，第三方组件继续遵守各自许可证。源码、演示素材和安装包不包含真实会议或个人配置。

- 支持 OpenAI 兼容 Chat Completions，配置 Base URL、模型 ID、API Key、JSON 模式、超时与分段长度。
- 密钥使用系统安全存储加密；支持清除，切换服务域名时不复用旧密钥。连接测试不包含会议材料。
- 保留 Codex CLI 调用方式；长文本分段/合并、行动项依据校验、缓存和取消共用统一流程。模型配置变化后重新生成，失败保留已有结果。
- 整合本地录音、系统音频、转写质量保护与窗口生命周期改进；移除一次性评测脚本、缓存和旧包。
- 新的原创应用图标、合成演示截图和产品 CG；完善首页、安装与开发说明。
- 精简运行时，使用固定版本的独立 Node 保持原生 ASR/VAD 兼容；FFmpeg 改为 LGPL 音频版，附对应源码和构建说明。

## 下载

- `Chui-Eve-1.2.0-macOS-arm64.zip`：Apple Silicon Mac 应用，ad-hoc 签名，未做 Apple 公证。
- `ffmpeg-8.0.1-source.tar.xz`：随应用分发的 FFmpeg 对应源码；以 `scripts/build-ffmpeg.cjs` 构建，无源码修改。
- `SHA256SUMS.txt`：附件 SHA-256，用于核对下载完整性。

FFmpeg 使用 LGPL-2.1-or-later，其[源码](https://ffmpeg.org/releases/ffmpeg-8.0.1.tar.xz)与构建方法一并提供。请阅读 [安装说明](https://github.com/vctest23469-bot/chui-eve/blob/v1.2.0/docs/INSTALL.md)。应用包不包含大模型或 Python 环境，首次使用需单独安装本地 ASR 模型。

## 验证范围

自动测试覆盖录音尾段、恢复、任务隔离、Range 回听、分段调度、窗口生命周期、模型完整性、API 配置加密/域名隔离、HTTP 协议、取消与错误处理。隔离 Electron 工作流覆盖设置保存与重启、连接测试、摘要/导图、导出、回听、全屏、深浅色和窄窗口。

30 项自动测试通过。最终 ZIP 解压后的应用通过真实 MLX 音频导入、转写、编辑保存和回听，以及合成音频驱动的实时录制、录制中字幕和停止后的尾段保存；原生 VAD 加载、深层签名与 ZIP 完整性检查通过。录制验证使用合成输入，未操作真实会议数据。

API 验证使用本机模拟服务，没有借用或发布真实密钥，不代表任意供应商的模型效果已验收。真实会议软件、麦克风和其他 Mac 设备的权限/安装体验仍需目标环境验证。AI 摘要与行动项需结合原文核对；不支持自动分离说话人。
