# 安装与首次使用

适用平台：Apple Silicon Mac，macOS 14 或更高。当前没有 Windows、Linux 或 Intel Mac 安装包。

## 安装应用

1. 从私有仓库的 Releases 下载 `Chui-Eve-1.2.0-macOS-arm64.zip` 和 `SHA256SUMS.txt`。需要已获仓库访问权限并登录 GitHub。
2. 使用 `shasum -a 256` 核对压缩包与校验文件。
3. 解压，将 `Chui Eve.app` 拖入「应用程序」。升级前结束录音并退出旧版。
4. 本包为 ad-hoc 签名，未做 Apple 公证。若系统阻止启动，请在核对下载来源后，通过 macOS「系统设置 → 隐私与安全性」允许打开；不要关闭系统整体安全保护。

应用包不包含大模型、Python 环境、真实录音或 API Key。已有本机模型可继续使用。

## 安装本地转写模型

首次安装需联网下载公开模型，日常转写仅从本地加载，不自动下载。

安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，然后获取本仓库源码。在仓库根目录执行：

```sh
# 安装 Python 环境和 Qwen3-ASR 1.7B 4-bit（权重约 1.6 GB）
zsh scripts/setup-mlx.sh 4bit

# 可选：BF16 权重约 4.1 GB，占用更多内存
zsh scripts/setup-mlx.sh bf16
```

脚本使用固定模型 revision 和 SHA-256 校验；权重失败时禁止启用。模型与环境位于用户的 `Library/Application Support/Chui Eve` 数据目录，与应用包分离。下载后打开「转写设置」选择对应模型；已安装的 BF16 和 4-bit 可独立切换。内存占用取决于模型、输入和系统状态，推荐至少 16 GB 内存；这是规划建议，不能替代目标设备验证。

## 录音与导入

- 点击「开始会议」录制麦克风。首次使用需要麦克风权限。
- 勾选「同时录制电脑声音」可采集线上会议；另需屏幕及系统音频录制权限，授权后可能需要重启应用。实际效果受会议软件和输出设备影响。
- 导入 MP3、M4A、WAV、FLAC、AAC、OGG 或常见 MP4/MOV/WebM 视频的音轨；可多选、拖入。少见编解码器不保证支持。
- 实时为分段转写，停顿或到达段长后返回，时间戳表示段落起点，不是逐字对齐；不自动分离说话人。
- 点击时间戳回听，点击文字编辑，离开编辑区自动保存。关闭窗口会收起到菜单栏，录音继续；退出前会保存尾段。

## 配置摘要 API

左侧「摘要模型」中选择「模型 API · OpenAI 兼容」，填写：

| 设置         | 说明                                                                                |
| ------------ | ----------------------------------------------------------------------------------- |
| API Base URL | 服务商的 API 根地址，例如 `https://api.openai.com/v1`；应用追加 `/chat/completions` |
| 模型名称     | 服务商实际开放的模型 ID，不能填写产品昵称                                           |
| API Key      | 你的服务密钥；无鉴权的本机服务可留空                                                |
| 超时         | 默认 180 秒，可设 15–600 秒                                                         |
| 每段字符数   | 默认 12,000；上下文较小的模型可调低至 2,000                                         |
| JSON 模式    | 默认开启；服务不支持 `response_format` 时关闭，结果仍必须为合法 JSON                |

点击「保存并测试连接」会发送一个不含转写内容的短请求，可能产生少量服务费用。成功后可在完成转写的记录中点击「提炼摘要」或「思维导图」。地址必须为 HTTPS；本机 `localhost`/loopback 服务可使用 HTTP。更换服务域名时需重新填写密钥。

现有 Codex 用户也可选择「Codex CLI · GPT-5.5」，使用本机 Codex 登录与额度；CLI 路径检查不代表登录、额度或模型权限通过。自定义 CLI 路径可用 `CHUI_CODEX_PATH` 指定。

**数据边界：录音与转写留在本机；点击提炼时，记录标题及转写文字会发送到所选服务。** 长文本会分段生成、合并并核对行动项，可能产生多次请求。服务商的数据保留政策与费用由其规则决定。密钥经 Electron `safeStorage` 和系统钥匙串加密后保存；系统安全存储不可用时拒绝保存密钥，不降级成明文。

## 结果与故障

- 摘要包括概览、明确结论、讨论主题、行动项和待确认问题；行动项通过原文引用核对，仍需人工回听。
- 导图支持收起、展开、缩放和全屏。摘要/导图可复制或导出 Markdown，正文可导出 TXT、Markdown、SRT、JSON。
- 修改标题或转写后会提示结果过期；更换模型配置后再次点击提炼会重新生成。已有结果不会自动删除。
- 401：检查密钥；403/404：检查模型权限和地址；429：检查额度或限流；超时：调低分段长度或提高超时。失败、取消和输出截断不会标记为成功，也不会覆盖已有有效结果。
- 数据目录内的 `library/records` 保存 WAV 与 JSON；移入应用废纸篓仍保留文件。清理应用不等于清理数据。不要把数据目录和摘要配置文件上传到仓库。

## 升级注意

Release 使用通用 ad-hoc 签名，与某些本机定制版的固定签名不同，升级后可能需要重新授予音频权限或重新填写 API Key。升级前可备份本地数据。仓库内 `scripts/install.cjs` 用于维护本机固定签名的开发安装，与对外 Release 打包分开，不会自动迁移签名身份。
